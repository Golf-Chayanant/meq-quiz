# แบบทดสอบ MEQ ฉบับภาษาไทย — Whoop Lab by Golf

เว็บแบบทดสอบ "คุณเป็นนกแบบไหน?" ทำงานบนมือถือเป็นหลัก ทำ 19 ข้อแล้วรู้ผลทันที
บันทึกผลเป็นรูปได้ แชร์ได้ และกรอกอีเมลรับผลได้ (ไม่บังคับ)

```
index.html / style.css / app.js   หน้าเว็บ
content.js                        คำถาม + คะแนน + เนื้อหาผลลัพธ์ 5 Type  ← แก้เนื้อหาที่นี่
config.js                         URL เว็บ / URL Apps Script / ลิงก์โพสต์
r/<type>.html                     ลิงก์แชร์แยกตาม Type (พรีวิวต่างกัน แล้วพาไปหน้าแบบทดสอบ)
og/                               รูปพรีวิวลิงก์ (ยังไม่มี — ดูข้อ 5)
apps-script/Code.gs               ตัวรับข้อมูลเบื้องหลัง: เก็บผลลง Sheet + ส่งอีเมล
build-gs.js                       แก้ content.js แล้วรัน `node build-gs.js` เพื่ออัปเดตเนื้อหาอีเมลใน Code.gs
```

ลองบนเครื่อง: `python3 -m http.server 8765` แล้วเปิด http://localhost:8765

## ขั้นตอนขึ้นเว็บ

1. **สร้าง repo public ใหม่** ชื่อ `meq-quiz` ใน GitHub (บัญชี Golf-Chayanant) แล้ว push โฟลเดอร์นี้ขึ้นไป
2. **เปิด GitHub Pages**: Settings → Pages → Source: Deploy from a branch → `main` / `(root)`
   เว็บจะอยู่ที่ `https://golf-chayanant.github.io/meq-quiz/` (ถ้าชื่อไม่ตรงนี้ ให้แก้ `SITE_URL` ใน config.js,
   `SITE_URL` ใน apps-script/Code.gs และ URL ใน `r/*.html` + `og:image` ใน index.html)
3. **ติดตั้งตัวรับข้อมูล** ใน Google Sheet MEQ เดิม: Extensions → Apps Script → สร้างไฟล์ใหม่ วางเนื้อหา `apps-script/Code.gs`
   → เลือกฟังก์ชัน `setup` แล้วกด Run 1 ครั้ง (จะสร้างแท็บ WebResults / WebEmails + ตั้งเวลาส่งอีเมลที่ค้างทุกเช้า 8 โมง)
   → Deploy → New deployment → Web app → Execute as: **Me** / Who has access: **Anyone** → คัดลอก URL ที่ลงท้าย `/exec`
   (ต้องติดตั้งแยกจากสคริปต์ onFormSubmit เดิม — ของเดิมไม่ต้องลบ)
4. **ใส่ค่าใน config.js**: `ENDPOINT` = URL `/exec` จากข้อ 3 / `POST_URL` = ลิงก์โพสต์ Facebook (หลังโพสต์แล้ว)
   ถ้า `ENDPOINT` ว่าง เว็บยังใช้ได้ แค่ไม่เก็บข้อมูลและซ่อนกล่องอีเมล
5. **รูปพรีวิวลิงก์ (กอล์ฟทำใน Canva)**: PNG ขนาด 1200×630 จำนวน 6 รูป
   `og/default.png` (ลิงก์หลัก) + `og/lark-strong.png` `og/lark.png` `og/middle.png` `og/owl.png` `og/owl-strong.png`
6. **เช็คพรีวิวก่อนโพสต์**: วางลิงก์ใน Facebook Sharing Debugger (developers.facebook.com/tools/debug) แล้วกด Scrape Again

## ต้องตัดสินใจ / เช็คก่อนเปิดใช้จริง

### ความเป็นส่วนตัว
- Sheet ที่เก็บข้อมูลควรตั้งการแชร์เป็น Restricted (Apps Script ยังทำงานได้ เพราะรันด้วยสิทธิ์เจ้าของ)
- คนที่ติ๊ก Consent = "yes" เท่านั้นที่ส่งข่าวสารได้ / คนขอลบข้อมูลทางอีเมลตอบกลับ ต้องลบแถวใน WebEmails ให้

### คะแนน
- **ข้อ 11** ใน Sheet ให้คะแนน 4/3/2/1 แต่ MEQ ต้นฉบับ (Horne & Östberg) ให้ 6/4/2/0
  ผลคือช่วงคะแนนของเวอร์ชันนี้เป็น **17-84** ไม่ใช่ 16-86 (อีเมลเดิมเขียน "/ 86") ส่วนเกณฑ์แบ่ง Type 70/59/42/31 มาจากต้นฉบับ
  → ถ้าจะใช้ตามต้นฉบับ แก้ตัวเลขข้อ 11 ใน `content.js` (เว็บเลยไม่โชว์ "/86" ไว้ก่อน)
- ข้อ 13, 14, 18 ตัวเลือกภาษาไทยถูกปรับจากต้นฉบับ (เช่น ข้อ 14 ต้นฉบับถามว่าจะจัดการการนอนอย่างไร) — คะแนนยังใช้ตาม Sheet

### เนื้อหาผลลัพธ์ (ย่อมาจาก Apps Script อีเมลเดิม)
ตัดออกแล้ว เพราะยังไม่ได้ fact-check: ป้าย "Walker's Tip/Strategy/Insight" ทั้งหมด, บรรทัด Biological State,
"นกฮูกถูกปลุก 6 โมงเสีย REM 60-90%", "ทำงานได้มากกว่าคนอื่น 2-3 เท่า", "อดนอนทำลายภูมิคุ้มกันหนักกว่ากลุ่มอื่น",
"สัดส่วน REM สูงมากช่วง 06:00-09:00", "ไฟ Daylight 10,000 lux"

ยังอยู่ในเว็บ — รอกอล์ฟยืนยันว่ามีที่มา:
- นกเช้าสายละมุน กฎข้อ 1 "ดื่มกาแฟแก้วแรกหลังตื่นประมาณ 1.5 ชม." (เดิมเขียนว่าเป็นของ Walker — ปกติเป็นคำแนะนำที่คนอ้าง Huberman)
- นกเช้าสายละมุน: สคริปต์เดิมเขียนเส้นตายคาเฟอีนไว้ 2 แบบ (ก่อน 14:00 และหลัง 15:00) → ตอนนี้เขียนกลางๆ ว่า "จบคาเฟอีนให้เร็ว" ควรเลือกเวลาเดียว
- นกฮูกสายประนีประนอม: ช่วงเวลาทอง 18:00-21:00 ทับกับช่วงออกกำลังกาย 19:00-20:30 (มาจากสคริปต์เดิม)
- นกฮูกตัวจริง กฎข้อ 1: สคริปต์เดิมเขียน "ป้องกันไม่ให้นาฬิกาชีวิตเลื่อนไป**เช้า**อีกวัน" → แก้เป็น "เลื่อนดึกขึ้น" ให้ตรงกับบรรทัดอื่นในสคริปต์เดียวกัน
- เวลาตื่น/นอน/ช่วงเวลาทอง/งีบ ของทุก Type เป็นเนื้อหาจากสคริปต์เดิมของกอล์ฟ

### ข้อจำกัดที่รู้แล้ว
- Gmail ส่วนตัวส่งอีเมลผ่าน Apps Script ได้จำกัดต่อวัน → เกินแล้วเก็บเป็น `pending` ส่งเช้าวันถัดไป (เว็บบอกคนกรอกไว้แล้ว)
- ปุ่มบันทึกรูป: มือถือที่รองรับจะเปิดเมนูแชร์ของเครื่อง (บันทึกลงรูปภาพได้) ถ้าไม่รองรับ เช่น ในเบราว์เซอร์ของแอป Facebook
  จะโชว์รูปให้กดค้างบันทึกแทน — **ยังไม่ได้ลองบนมือถือจริง** ควรลองทั้ง iPhone และ Android ผ่านแอป Facebook ก่อนโพสต์
- Facebook ไม่ให้เติมข้อความในโพสต์ที่แชร์ล่วงหน้า ปรับได้แค่รูปและหัวข้อในพรีวิวลิงก์
